# =============================================================================
# JARVIS - consolidated requirements
# =============================================================================
# This repo is a monorepo of three local packages:
#   - jarvis-shared        (shared contracts / domain models)
#   - jarvis-backend       (orchestration backend: FastAPI, auth, memory, scheduler)
#   - jarvis-local-agent   (Windows runtime: wake word, STT/TTS, tray)
#
# The three local packages are installed in editable/develop mode:
#     pip install -e jarvis-shared -e jarvis-backend -e jarvis-local-agent
#
# This file lists their third-party runtime dependencies in one place so the
# whole project can be installed from a single file. Versions are pinned to the
# resolved set in constraints.txt where available; unpinned extras use the
# lower bounds declared in each package's pyproject.toml.
#
# Install everything:
#     pip install -r requirements.txt
# =============================================================================
